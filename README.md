# Originle game — guess pacing notes (2026-11-02)

Originle is a daily puzzle: watch short clips of a real guest and guess which country they are from (up to **3 guesses**, **8 clues**). Free to play on the official site [originle.io](https://originle.io).

## Fan companion (unofficial)

For clue titles, archive browsing, and score notes, use the unofficial fan companion **[originle.app](https://originle.app/)**. It is **not** the official Originle site and does not replace playing the clips on originle.io.

## Quick pacing tip

Build a 2–3 country shortlist from early clues before spending guess 1; use mid clues to eliminate; save guess 3 for after a decisive late clue.
